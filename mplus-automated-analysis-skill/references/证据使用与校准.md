# 证据使用与校准

本页规定 Skill 怎样使用参考资料。目标是让提示有依据，但不把经验值变成“论文及格线”。

## 三类依据

| 类型 | 可以回答什么 | 不能怎样用 |
|---|---|---|
| Mplus 官方手册、示例、Web Note 和版本说明 | 命令怎么写、默认值、版本功能、输出字段 | 不能仅因语法可运行就证明方法适合当前研究 |
| 同行评议的方法论文和权威专著 | 估计方法的条件、性能、风险和解释边界 | 不能把特定模拟条件下的数值扩大为全领域硬标准 |
| Skill 内部筛查线 | 及时提醒新手核对尺度、样本量或极端结果 | 只能触发提醒，必须明说“内部筛查线”，不得写成文献统一阈值 |

## 当前校准边界

- **拟合指数**：Hu & Bentler (1999) 的数值只用于定位连续数据 ML 模型中的可疑拟合，且原文强调两指标组合。分类指标的 WLSMV/DWLS 结果不机械照搬；低自由度模型不用 RMSEA 单独否决。
- **样本量**：200、300 和 50 仅是防止遗漏的筛查线。EFA、SEM、mixture 和多层模型的所需样本取决于载荷、效应、类别分离、群体数、缺失与模型复杂度。正式规划优先使用预实验或可靠文献的预期参数做模型特定 Monte Carlo。
- **两题因子**：“每个因子至少 3 题”是稳妥设计建议，不是无条件数学定理。两题因子可能在更完整模型或额外约束下识别，但需显式提醒可检验信息较少。
- **信效度**：复合信度/omega 近似值只在所用公式与测量模型相符时计算。交叉载荷、相关残差、Heywood 解或分类指标必须说明额外条件。Fornell-Larcker 通过不等于已证明区分效度。
- **测量不变性**：比较潜均值通常需要截距或阈值不变；比较结构关系的最低要求与均值比较不完全一样，也可能存在有依据的部分不变。
- **纵向模型**：本 Skill 的标准 CLPM/RI-CLPM 入口要求 3 个及以上时点，这是产品的自动化边界。两波交叉滞后路径模型并非在数学上一律不能做，但对动态过程和稳定个体差异的识别有明显限制。
- **LPA/LCA**：唯一值不超过 10 只触发尺度确认，不自动宣判变量是分类或连续。类别数选择要先确认 loglikelihood 稳定，再综合信息准则、TECH11/TECH14、分类质量、类别大小和实质解释。
- **版本**：版本历史页以有日期的发布条目为准。当前只有 macOS Apple Silicon + Mplus 8.3 是实机 target；其他 8.x/9.x 是未实机认证的 provisional 兼容。
