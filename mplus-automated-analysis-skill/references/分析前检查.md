# 分析前检查

这份检查只保留会影响 Mplus 结论的必要问题，不要求用户填写复杂表格。Agent 应优先从研究方案、问卷和已有对话中提取；缺少关键信息时再询问。

## 研究问题与设计

- 最终要比较、解释或预测的是什么？
- 数据是横截面、纵向、嵌套、多组还是复杂抽样？
- 处理、时间点、组别、学校/班级/个体等单位是否被正确记录？
- 哪些变量是指标、潜变量、协变量、结果、分组、聚类、权重或 ID？
- 研究设计支持的是描述、关联、预测还是因果解释？观察数据不得仅因使用 SEM 就改写成因果结论。

## 数据收集与测量

- 是否存在随机化、重复测量、批次、区组、量表版本或测量方式变化？
- 缺失是怎样产生的？仅凭缺失比例不能判定 MCAR、MAR 或 MNAR。
- 异常记录能否回查问卷、仪器或录入日志？算法标记不等于应删除。
- 是否有预先确定的排除、计分、反向题和变量转换规则？

## 样本量与功效

- 优先依据预期效应、类别分离、最小类别、聚类数和完整模型做模拟功效分析。
- Runtime 的样本量数字是非阻断性规划提醒，不是“达到即可可靠”的硬阈值。
- 样本量不足时仍可按用户要求运行，但报告必须保留风险、规划参考和依据。

## 敏感性分析

只比较有研究理由的替代设定，例如合理的缺失处理、估计量、类别范围或理论模型。不得批量跑模型后挑显著结果。
