# 分析选择与提问

用户可以只说研究问题，不要求他先知道方法名称。先从数据、问卷和已有说明提取信息，再补问会改变分析路线的缺口。

## 常规统计与测量

| 用户想知道什么 | 推荐入口 | 最少确认 |
|---|---|---|
| 样本和变量大致怎样 | `preliminary` + `descriptive` | 分析变量、特殊缺失码 |
| 量表是否稳定 | `preliminary` + `reliability`，随后视需要做 CFA | 题项归属、反向题是否已计分、分量表结构 |
| 两个或多个变量是否相关 | `preliminary` + `correlation` | 变量尺度、Pearson 或 Spearman、是否需要多重校正 |
| 两组或多组是否不同 | `preliminary` + `difference` | 独立或配对、分组变量、结果变量、是否事后比较 |
| 量表结构未知 | `run-spec` + `efa` | 连续或有序题项、候选因子范围、是否留出 CFA 样本 |
| 验证预设量表结构 | `run-spec` + `cfa` | 每个因子的题项、题项类型、残差相关是否有事前依据 |
| 比较组间或时间上的量表含义 | 测量不变性引导流程 | 分组或波次、连续或有序题项、比较目标 |

## 回归、中介与结构模型

| 用户想知道什么 | 推荐入口 | 最少确认 |
|---|---|---|
| 多个变量怎样预测连续结果 | `run-spec` + `regression` | 结果、预测变量、控制变量、分类预测变量编码 |
| 多个变量怎样预测二分类结果 | `run-spec` + `logistic` | 结果的两类编码、参照类别、预测变量编码 |
| X 是否通过 M 影响 Y | `run-spec` + `mediation` | X、M、Y、协变量、观测或潜变量、Bootstrap 次数 |
| X 是否依次通过 M1、M2 影响 Y | `run-spec` + `serial-mediation` | 中介先后顺序及其理论依据 |
| X 对 Y 的作用是否随 W 改变 | `run-spec` + `moderation` | X、W、Y、中心化方式、交互项方向 |
| 间接效应是否随 W 改变 | `run-spec` + `moderated-mediation` | W 调节哪一段、条件值、变量是否连续观测 |
| 同时处理测量模型和结构路径 | `run-spec` + `sem` | 因子题项、结构路径、协变量、间接效应 |
| 比较不同组的结构路径 | 多群组 SEM 引导流程 | 先完成测量不变性，再确认要比较的路径 |

## 纵向、混合与多层模型

| 用户想知道什么 | 推荐入口 | 最少确认 |
|---|---|---|
| 两个变量跨时间相互预测 | `run-spec` + `clpm` | 本 Skill 标准入口要求三波及以上、每波变量、真实间隔、同期残差关系；两波模型转受限路径分析 |
| 区分个体间与个体内的跨期关系 | RI-CLPM 引导流程 | 通常需要三波及以上；更多波次可增加动态信息，但“四波”不是通用硬门槛。还需核对测量不变性、间隔和版本 |
| 研究平均起点和变化速度 | `run-spec` + `growth` | 至少三波、真实时间分数、时间不变与时变协变量 |
| 寻找不同增长轨迹类别 | GMM/LCGA 引导流程 | 先完成单类增长模型、类别范围、类内方差设定 |
| 寻找横截面的潜在人群 | `lpa` 或 `run-spec` + `lca` | 指标类型、类别范围、ID、是否标准化 |
| 数据嵌套在班级或学校 | 多层引导流程 | 聚类变量、层级内外变量、聚类数、中心化方案 |
| 同时估计两层潜变量关系 | 多层 SEM 引导流程 | 每层因子与路径、跨层效应、随机斜率 |
| 在嵌套数据中识别潜在剖面 | 多水平 LPA 引导流程 | 类别位于个体层、群体层或两层，聚类数和组内样本量 |

## 路由原则

- 横截面数据不能因为有多个变量就路由到交叉滞后或增长模型。
- 分组差异若涉及潜变量，先检查测量不变性，再比较潜变量均值或结构路径。
- 量表信度不能代替因子结构；Cronbach alpha 不能证明单维性。
- 调节变量是分类变量时先明确参照组和编码，不自动把任意数字编码当连续变量。
- 多层分析先确认聚类单位和层级，不能只因数据里有“学校”列就自动使用两层模型。
