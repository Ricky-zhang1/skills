# Mplus 新手常见问题

这份清单优先处理会改变样本、模型含义或结论的错误。不要把所有警告都写成失败，也不要忽略会使参数不可信的警告。

| 常见情况 | 为什么会出问题 | Skill 应怎样处理 |
|---|---|---|
| SPSS 描述统计正常，Mplus 却提示方差过大 | 常见原因不是软件算法不同，而是缺失码进入计算、小数点/单位错误或变量列错位 | 同时输出源数据与 Mplus 数据的均值、标准差和范围；逐值回读转换文件。极端量纲先提示回查，不自动标准化；转换不一致则停止 |
| 手工 DAT 使用 UTF-8 时意外终止，改成 ANSI 后能运行 | 旧版 Mplus、中文文本和文件编码组合可能引发读取问题，但“改 ANSI”不是适用于所有数据的规则 | 不让用户反复另存。自动识别源文件编码，再生成只含 ASCII 数字的 DAT 和只含 ASCII 语法的 INP，并验证文件字节 |
| Excel、SAV 或 TXT 直接改成 DAT 后列错位 | Mplus 按位置读无表头数据 | 始终生成变量对应表，核对 NAMES、USEVARIABLES 和实际输出变量顺序 |
| 原来 1444 行，Mplus 只使用 722 行 | NAMES 声明和实际字段数不一致时 Mplus 可能跨行拼接；预测变量缺失、筛选和分组也会减少样本 | 先核对导出文件确为 1444 行且每行字段数一致；若转换已通过，再定位缺失、筛选和模型有效样本，不能只凭总行数猜原因 |
| 新增中文学校名、班级名以后模型突然不能运行 | 中文文本不应直接进入 Mplus 的数值数据区；若变量清单一起错位，后续所有列都会被错读 | 无关文本列不导出；作为 cluster/group 时自动编码。转换前后核对二分类变量值域，避免本应为 0/1 的变量出现 3.5 等不可能均值 |
| 中文名、长变量名或特殊字符报错 | Mplus 变量名有长度和字符限制 | 自动映射为 8 位以内 ASCII 名称，报告和结果再映射回原名 |
| `999`、`-99` 被当成真实分数，或合法年龄 `99` 被误删 | 缺失码没有声明、不同变量混用，或只靠固定哨兵表猜测 | 同时支持全局和逐变量缺失码；合法疑似值可以按变量明确确认为有效。SAV 中已有的 SPSS 用户缺失定义写入元信息 |
| Mplus 使用的样本量比原数据少 | 结果变量全缺失、预测变量缺失、筛选条件或分组造成删样本 | 比较输入、转换和 Mplus 实际样本数；特别提示缺失在 x 变量时的处理边界 |
| Likert 题未核对连续/有序分类处理 | 处理方式会改变估计量、阈值、载荷和拟合统计；“Likert 一律分类”或“五级一律连续”都过于简化 | 结合类别数、各类频数/阈值、偏态、样本量和目标参数决定；唯一值数只用于触发人工确认（Rhemtulla et al., 2012） |
| 反向题未计分就做信度或因子分析 | 题项方向不一致会制造低相关和假因子 | 信度入口要求 `items_aligned=true`，未确认时停止 |
| 同一批样本先 EFA 再 CFA | 后续 CFA 不是严格的样本外确证，但盲目拆分小样本也会让 EFA 和 CFA 都不稳定 | 有充足样本时使用拆分或独立样本；样本有限时可使用同一样本，但要明确写成探索后内部复核，不冒充独立验证 |
| CFA 出现 `df=0` 和完美拟合 | 恰好识别模型不能用拟合指数判断优劣 | 报告标记恰好识别，转向载荷、误差、结构和理论检查 |
| 根据修改指数不断加残差相关 | 容易把样本噪声写进模型 | 只允许有题目内容、方法效应或纵向同题依据的残差相关，并记录理由 |
| 未确认目标所需的测量不变性就比较组均值或路径 | 各组/各波潜变量可能不在可比的测量尺度上 | 先做配置不变；比较因子方差、协方差或结构关系通常至少需载荷不变，比较潜均值通常还需截距/阈值不变。局部不变性需明确报告，不用一套层级要求覆盖所有比较目标（Putnick & Bornstein, 2016） |
| Logistic 回归把分类预测变量也写进 `CATEGORICAL` | Mplus 的 `CATEGORICAL` 主要声明因变量 | 预测变量先按研究设计建立虚拟变量或对比编码，并明确参照组 |
| 中介路径显著就写成因果机制 | 横截面关联不能建立时间顺序和无混杂 | 报告区分统计间接效应与因果中介，保留研究设计边界 |
| 链式中介只写 `Y IND M N X` 但回归路径缺失或顺序相反 | 研究顺序是 `X→M1→M2→Y`，而 Mplus 的串联 `IND` 语句从结果端反向列出中介；手工写法很容易混淆 | 用户只需按研究顺序提供 X、M1、M2、Y。Runtime 检查每一段回归路径，再自动生成 Mplus 所需的反向 `IND` 顺序 |
| 调节分析没有说明中心化和条件值 | 主效应含义和条件效应位置不清楚 | 记录中心化方式；条件值用有意义取值或均值及标准差，不机械使用正负 1 |
| 两波数据直接套用本 Skill 的 CLPM、RI-CLPM 或增长模型 | 两波路径模型可以存在，但对时间趋势、稳定个体差异和个体内动态的区分能力很有限 | 本 Skill 的标准 CLPM/增长入口以三波为产品边界；两波设计转入受限路径模型并降低时序解释。RI-CLPM 需明确分离稳定个体间差异与个体内波动，不因为纵向就自动获得因果解释（Hamaker et al., 2015） |
| 时间间隔不等却使用 `0 1 2` | 斜率含义与真实时间不符 | 使用真实间隔作为 `time_scores` |
| 多层模型只看总样本量 | 高层单位数可能不足，标准误和随机效应不稳定 | 同时报告聚类数、组内样本量范围和层级参数数量 |
| MSEM 报“组内没有变异”或“群体层变量在组内有变异” | WITHIN/BETWEEN 变量角色与数据实际结构不一致，也可能是聚类编号或变量列错位 | 自动逐聚类检查。纯 BETWEEN 变量组内变化时停止并列出示例组；WITHIN 变量只在部分组无变异时提示，不把所有情况都当成致命错误 |
| 个体层变量未中心化、中心化层级错误，或代码声称中心化但没有 `CENTER` | 个体内和个体间效应混在一起 | 每个实际预测变量明确选择组均值、总体均值或不中心化；Runtime 检查并真实生成 `DEFINE: CENTER` |
| LPA/LCA 只看最低 BIC 或最高 Entropy | 局部最优、小类别和分类不确定性会被忽略 | 检查最佳 loglikelihood、TECH11/14、类别规模、后验概率和实质解释 |
| 把最可能类别当成无误差观测分组 | 分类误差会传入后续比较 | 优先使用三步法、BCH 或联合模型；直接导出的类别只用于描述和核对 |
| 输出写着正常结束就忽略 warning | 非正定矩阵、负方差和不可识别仍可能存在 | 读取 TECH1/TECH4 和重大警告；正常结束不能覆盖识别问题 |
| 样本量低于某个数字就一律拒绝分析 | 所需样本受效应、模型和类别分离影响 | 允许继续运行，报告当前样本、规划参考、模型特有风险和模拟功效建议 |
