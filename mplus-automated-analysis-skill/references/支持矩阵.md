# Mplus 分析支持矩阵

`catalog` 是运行时真值源。本文档用于帮助 Agent 理解不同等级。

## 产品优先范围

默认 `catalog` 只显示通常会优先使用 Mplus 的核心模型。当前范围是：

- 初步统计：描述统计、信度、相关与差异分析；
- 测量模型：EFA、ESEM/bifactor ESEM、CFA、多组与纵向测量不变性；
- 结构模型：多元/Logistic 回归、调节、SEM、观测或潜变量中介、链式中介、有调节的中介、CLPM 与 RI-CLPM；
- 混合模型：LPA、LCA、GMM/LCGA、LTA/HMM；
- 纵向模型：潜在增长、平行过程增长；
- 数据结构：多层 CFA/SEM/中介、复杂抽样。

其中有些仍处于引导实现阶段。核心范围表示“应当建设”，不等于“当前已全自动交付”。

## 正在实现的引导模块

- 多组 CFA 与配置/载荷/截距/阈值不变性；
- 多群组 SEM、多层中介和复杂跨层潜变量交互；
- GMM、LCGA、LTA/HMM；
- RI-CLPM、多水平 LPA、ESEM/bifactor ESEM；
- 复杂抽样。

这些模块在发布包中不得显示为“无提示自动完成”，直到输入约束、输出反校验和实机回归全部完成。

## 非默认扩展

路径回归作为 SEM 和中介的底层能力保留，但不单独作为产品重点。IRT、生存、缺失数据/多重插补与 Monte Carlo 仅在研究问题确有需要时启用。贝叶斯/BSEM、DSEM、多层 mixture 和任意复合模型属于专家扩展。这些分析不存在一份适用于所有研究的通用模板；Agent 必须先形成完整分析设计，再根据官方语法与专题资料执行。

## 平台状态

| 平台 | 当前状态 |
|---|---|
| macOS Apple Silicon | 主要目标；Mplus 8.3 已在一台 M 系列开发机实测，首次安装仍需本机自检 |
| Windows x64 | 路径、PowerShell、自动测试和构建层兼容；没有真机与真实 Mplus 验证，不得标为已认证 |
| macOS Intel | 保留构建兼容；未实机验证，不是当前优先交付平台 |
