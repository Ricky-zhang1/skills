# LPA 1—K 类标准分析规范（v0.3 Alpha 9）

## 1. 适用范围

本标准模块用于以多个连续观测变量作为剖面指标的潜在剖面分析。默认比较 1—5 个类别。标准模块不处理混合指标、协变量、远端结果、多层结构、纵向转移或增长混合模型。

## 2. 基线模型

基线参数化对应 Mplus User's Guide Example 7.9 的核心结构：

- 指标为连续变量；
- `TYPE = MIXTURE`；
- 各类别的指标均值可不同；
- 指标方差默认在类别间相等；
- 类内指标协方差默认为 0；
- 估计量使用 MLR。

这是一种常见且相对简约的 LPA 起点，但不是所有研究的唯一正确模型。若局部独立假设明显不合理，或研究问题要求类别特异方差，应切换到相应扩展模板，不允许在基础模板上临时随意改写。

## 3. 数据处理

### 3.1 不默认标准化指标

“标准化流程”与“变量做 Z 标准化”必须区分。Runtime 不会因为不同指标量纲不同就自动 Z 标准化。若用户选择标准化，必须：

1. 在《分析设计清单》中记录；
2. 保存标准化前均值和标准差；
3. 保留原始变量到分析变量映射；
4. 报告中明确说明。

### 3.2 缺失值

Runtime 将源数据中的缺失值统一写成内部缺失码，例如 `-999999`，并在 Mplus `VARIABLE` 中显式声明。不得把缺失值错误地当成真实观测值。

### 3.3 Mplus 变量名

为了兼容不同版本和路径环境，内部变量名采用 ASCII 短名，例如 `V000001`。用户原始变量名完整保存在变量对应表中。不得简单截断长变量名导致重名。

### 3.4 低基数指标

只有不超过 10 个非缺失唯一值的指标可能是等级或分类变量，标准模式默认停止，不能仅凭数值编码自动当作连续指标。研究者明确确认按连续变量处理后才能继续，并将确认写入分析设计清单。真正的分类指标应切换到 LCA 或混合指标模型，不能套用基础 LPA。

## 4. 随机起始值与局部最优

混合模型存在局部最大值风险。本 Skill 不采用一个固定随机起始值作为“万能标准”，而使用逐级升级策略：

- 初筛：`STARTS = 200 40`
- 验证：`STARTS = 1000 200`
- 困难模型：`STARTS = 5000 1000`

这些数值属于软件工程策略，不宣称是文献统一规定。每一级都检查输出中的最佳 loglikelihood 是否被重复获得。若未重复，自动升级；仍无法稳定时，该模型不能进入最终类别数比较。

Mplus 官方 Example 7.9 明确提示，即使最佳值已重复，也应通过增加随机起始值确认该值仍能获得并重复。TECH14 采用官方 Web Note 14 的两阶段思想：先找到稳定解，再运行 TECH14；若 TECH14 bootstrap 存在局部最优或不收敛警告，则该 p 值标记为不可用。

## 5. 类别数比较

### 5.1 硬门槛

候选模型至少满足：

- Mplus 正常结束；
- 无 `*** ERROR`；
- K>=2 时最佳 loglikelihood 已重复；
- 设计清单与 Mplus 实际识别的指标、类别数、估计量一致。

### 5.2 综合证据

在通过硬门槛后综合：

- AIC；
- BIC；
- 样本量调整 BIC；
- TECH11；
- TECH14；
- Entropy；
- 平均后验分类概率；
- 类别比例；
- 参数估计是否异常；
- 类别能否形成有意义的实质解释。

类别数不存在一个可以脱离模型稳定性和实质解释而机械使用的单一指标。Entropy 用于说明分类清晰程度，不单独决定类别数。

### 5.3 自动推荐逻辑

Runtime 只负责形成“统计证据候选”：

1. 排除硬门槛不通过的模型；
2. 找到 BIC 最小的有效模型作为主要统计候选；
3. 检查其与 K-1 模型的 TECH11/TECH14 证据；
4. 检查最小类别规模、Entropy 与后验概率；
5. 若多项证据一致，标记为“统计证据较集中”；
6. 若证据冲突，标记为“证据不一致”，交由 Agent 结合理论解释。

不输出“BIC最低所以一定选K类”这种表述。

## 6. SAVEDATA

K>=2 的候选模型默认保存：

- 最可能类别归属；
- 每个类别的后验概率；
- ID；
- Mplus SAVEDATA 中一并写出的分析变量。

Runtime 根据 `.out` 中 `SAVEDATA INFORMATION` 的变量顺序解析数据，不能猜测列名。解析完成后与原始 ID 做一对一回查，再输出 Excel。

## 7. 最终报告最低内容

- 数据与样本说明；
- 指标变量及其处理；
- LPA 模型设定；
- 1—5 类模型比较表；
- 模型稳定性检查；
- 推荐类别数及证据；
- 各类别比例；
- 各指标在类别中的估计均值；
- 分类质量；
- 重要警告与限制；
- 代码说明；
- 方法来源与参考文献。
