# 进阶模型工作流

这些模型可以由 Skill 引导完成，但不使用一份万能语法。先完成前置模型，再生成最终代码。

## 测量不变性

1. 分别检查各组或各波 CFA 是否可接受。
2. 连续题项依次比较配置、载荷、截距不变性；需要比较残差时再做严格不变性。
3. 有序分类题项比较载荷和阈值，估计量与参数化保持一致。
4. 记录每一步释放的参数及理论依据，不根据修改指数批量解除约束。
5. Mplus 8.3 使用显式多组或纵向约束；8.9 以后只有在版本匹配且流程已核对时才考虑自动纵向不变性功能。

官方入口为 [Chapter 5 Examples](https://www.statmodel.com/usersguide/chapter5.shtml)。

## 多群组 SEM

1. 先达到研究目标所需的测量不变性层级。
2. 先估计各组自由结构路径模型。
3. 只约束有理论问题的路径，使用 Wald 或嵌套模型比较。
4. 报告各组估计值和路径差异，不用“一组显著、另一组不显著”代替组间差异检验。

## 多层回归、SEM 与跨层效应

1. 确认聚类单位、聚类数和每个聚类的样本量。
2. 区分纯个体层、纯群体层和同时含两层变异的变量。
3. 说明中心化方式及其对应的个体内或个体间解释。
4. 随机斜率和跨层调节只在斜率确有层间变异且聚类数足够时进入模型。
5. 基础两层回归、CFA/SEM 和随机斜率可在确认后用 `run-spec`，并设置 `confirmed_guided=true`。

官方入口为 [Chapter 9 Examples](https://www.statmodel.com/usersguide/chapter9.shtml)。

## RI-CLPM

1. 本 Skill 的 RI-CLPM 引导流程通常要求三波及以上；更多波次可增加动态信息，但不把“四波”写成通用数学硬门槛。同时核对波次间隔和缺失模式。
2. 多指标模型先检验纵向测量不变性。
3. 分开个体间随机截距与个体内波动，再设自回归、交叉滞后和同期关系。
4. Mplus 8.3 使用传统显式分解语法；8.9 以后才可考虑简化的 `^` 语法。
5. CLPM 与 RI-CLPM 回答的问题不同，不根据哪个显著来选择模型。

官方入口为 [Mplus RI-CLPM Topic Page](https://www.statmodel.com/RI-CLPM.shtml)。
解释边界参见 Hamaker, Kuiper, & Grasman (2015), https://doi.org/10.1037/a0038889。

## GMM 与 LCGA

1. 先建立无类别增长模型，确认时间分数和增长形态。
2. LCGA 固定类内增长因子方差为零；GMM 允许类内变异，两者不是可随意互换的名称。
3. 从一类开始逐步增加类别，检查随机起始值、局部最优、类别规模和估计边界。
4. 协变量和远端结果在无条件类别模型稳定后加入，避免它们先改变类别形成。
5. 类别数选择同时看信息准则、LRT、稳定性和轨迹的实质意义。

官方入口为 [Chapter 8 Examples](https://www.statmodel.com/usersguide/chapter8.shtml)。

## 多水平 LPA

1. 先回答类别位于个体层、群体层还是两层；这三种模型含义不同。
2. 检查聚类数、组内样本量、指标在组内和组间的变异。
3. 先分别了解单层 LPA 和空多层模型，再组合为 `TYPE=TWOLEVEL MIXTURE`。
4. 明确个体层类别、群体层类别、协变量和跨层预测的先后顺序。
5. 不把普通 LPA 加 `CLUSTER` 当成多水平 LPA。

官方入口为 [Chapter 10 Examples](https://www.statmodel.com/usersguide/chapter10.shtml)，其中 Example 10.6、10.7 和 10.9 展示两层潜类别与两层增长混合结构。
