# Changelog

## v1.1beta

- Expanded the controlled runtime to preliminary statistics, regression, Logistic regression, moderation, serial and moderated mediation, basic CLPM, and confirmed two-level models.
- Added measurement-quality guidance before downstream SEM, mediation, and profile analysis.
- Calibrated fit, reliability, sample-size, invariance, longitudinal, LPA/LCA, and version rules against official Mplus documentation and peer-reviewed methods literature.
- Added novice-focused checks for text encoding, variable order, long IDs, missing codes, multilevel centering, convergence, and saved-data joins.
- Passed 111 automated tests and a fresh Apple Silicon plus Mplus 8.3 self-test.

## v1.0beta

- First public beta release.
- Simplified installation into one message that users can send to any Skill-capable Agent.
- Added a short explanation of the workflow and how the Skill checks each analysis.

## v0.3.0-alpha.9

- First public GitHub release.
- Added controlled workflows for EFA, CFA, SEM, mediation, basic linear growth, LPA, and LCA.
- Added local environment detection, dependency bootstrap with explicit consent, and a local Mplus self-test receipt.
- Added output parsing, Excel and CSV exports, result reports, citations, data-integrity checks, and privacy exclusions.
- Added an installation guide, support boundaries, a visual workflow, and explicit Mac Apple Silicon plus Mplus 8.3 testing status.

## Compatibility boundary

- Mac Apple Silicon plus Mplus 8.3 received real-machine testing.
- Windows, Mac Intel, and Mplus 9.x retain compatibility and self-test paths, but have not received full real-machine regression testing.
