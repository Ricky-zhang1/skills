# 完整工作流程

## 总览

组态思维文献定位法是一个四步流程，将具体研究问题转化为可检索的理论框架。

```mermaid
graph LR
    A[具体问题] --> B[概念拆解]
    B --> C[条件集合]
    C --> D[真值表]
    D --> E[检索策略]
```

---

## 第一步：概念化与拆解 (Conceptualization)

### 目标
将模糊的研究对象转化为清晰的学术维度

### 操作步骤

#### 1.1 识别核心要素

从用户描述中提取四类要素：

| 要素类型 | 定义 | 示例问题 |
|----------|------|----------|
| **行动者 (Actors)** | 研究的主体 | "谁在做这件事？" |
| **情境 (Contexts)** | 发生的环境 | "在什么背景下？" |
| **活动 (Activities)** | 核心行为/现象 | "在做什么？" |
| **关切 (Concerns)** | 核心问题/结果 | "为什么重要？" |

#### 1.2 提炼抽象维度

将具体要素转化为学术界通用的抽象属性：

**抽象化策略：**
- 从具体到一般
- 使用领域通用术语
- 保持层次一致性

**示例：**
```
"工程研究生" → "新手专业人士" / "受训者" / "知识工作者"
"中国企业" → "新兴市场企业" / "后发企业"
"疫情期间" → "危机情境" / "高不确定性环境"
```

### 输出格式

```markdown
## 要素识别表

| 要素类型 | 具体描述 | 抽象维度 |
|----------|----------|----------|
| 行动者 | ... | ... |
| 情境 | ... | ... |
| 活动 | ... | ... |
| 关切 | ... | ... |
```

---

## 第二步：生成条件集合 (Condition Sets)

### 目标
将抽象维度转化为可操作的因果条件

### 操作步骤

#### 2.1 转化因果条件

生成 **4-6个** 核心解释条件：

**命名规范：**
- 使用学术化命名 (C1, C2, C3...)
- 条件应可被观察/测量
- 条件间应相对独立

**条件类型：**
| 类型 | 描述 | 示例 |
|------|------|------|
| 结构性条件 | 相对稳定的背景因素 | 组织规模、制度环境 |
| 能动性条件 | 行动者的特征/能力 | 专业技能、社会资本 |
| 过程性条件 | 动态变化的因素 | 学习过程、适应策略 |

#### 2.2 链接学术领域

为每个条件指明相关的理论流派或学术领域：

```markdown
## 条件集合

| 条件 | 名称 | 定义 | 关联领域 |
|------|------|------|----------|
| C1 | ... | ... | 角色理论 |
| C2 | ... | ... | 社会资本理论 |
| C3 | ... | ... | 制度理论 |
| C4 | ... | ... | 学习理论 |
| C5 | ... | ... | 组织行为学 |
```

---

## 第三步：构建概念型真值表 (Conceptual Truth Table)

### 目标
通过条件组合识别不同的理论解释路径

### 操作步骤

#### 3.1 定义结果变量

将"核心关切"拆解为 **1-2个** 可观测的结果：

```markdown
## 结果变量

| 代码 | 名称 | 定义 | 测量指标 |
|------|------|------|----------|
| Y1 | ... | ... | ... |
| Y2 | ... | ... | ... |
```

#### 3.2 构建组态矩阵

使用 0/1 表示条件的缺失/存在：

**组态选择原则：**
1. 选择有**理论张力**的组态
2. 覆盖**主流解释**和**替代解释**
3. 包含**极端案例**和**典型案例**

**示例矩阵：**

| 组态 | C1 | C2 | C3 | C4 | 预期结果 | 理论流派 |
|------|----|----|----|----|----------|----------|
| T1 | 1 | 1 | 1 | 0 | Y1↑ | 主流解释 |
| T2 | 0 | 1 | 1 | 1 | Y1↑ | 替代路径 |
| T3 | 1 | 0 | 0 | 1 | Y1↓ | 反例分析 |

#### 3.3 匹配理论文献

为每个组态指明对应的文献流派：

**匹配原则：**
- 按"逻辑相似"而非"案例相同"
- 寻找解释同一机制的不同领域
- 跨学科对话增加创新性

---

## 第四步：生成检索与综述策略 (Strategy)

### 目标
产出可执行的文献检索和组织方案

### 输出内容

#### 4.1 关键词组合

```markdown
## 检索词组合

### 中文
- 组合1: [C1关键词] + [Y1关键词]
- 组合2: [C2关键词] + [Y2关键词]
- ...

### English
- Combination 1: [C1 term] AND [Y1 term]
- Combination 2: [C2 term] AND [Y2 term]
- ...
```

#### 4.2 综述结构建议

```markdown
## 综述章节结构

### 第一章：主流解释 (T1组态)
- 核心论点
- 代表文献
- 实证证据

### 第二章：替代路径 (T2组态)
- 核心论点
- 代表文献
- 与主流的对话

### 第三章：边界条件 (T3组态)
- 反例分析
- 情境修正
- 理论边界

### 第四章：综合与贡献
- 组态比较
- GAP定位
- 本研究位置
```

#### 4.3 贡献定位

明确研究的创新点：

| 贡献类型 | 描述 |
|----------|------|
| **填补空白** | 某组态缺乏研究 |
| **挑战假设** | 反例推翻主流 |
| **整合视角** | 跨组态对话 |
| **情境拓展** | 新情境下的验证 |

---

## 质量检查清单

- [ ] 条件数量在 4-6 个之间
- [ ] 抽象层次一致
- [ ] 每个结果至少 2-3 条路径
- [ ] 真值表有理论张力
- [ ] 文献匹配按"逻辑相似"原则
- [ ] GAP定位清晰
